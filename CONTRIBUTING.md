# Contributing

This repository is **AI-maintained**. Please read this before opening anything.

> **Note on issues:** the issue tracker for this repository is intentionally **disabled** — it is a small,
> single-owner project and we do not want an unread inbox. Pull requests can still be opened, and that is why
> this file exists. If you need to reach a human, contact the owner **@xiaocong610**.

## 1. AI-generated pull requests: say so up front

If your change was produced with an AI assistant, **say so in the PR description**. Some patches here are written
by an AI; we would rather discuss the rationale up front than leave a PR unreviewed.

## 2. What we welcome

- **Corrections** to documentation, especially if a statement is wrong or outdated.
- **Small, focused patches** to the tools: bug fixes with a minimal reproduction, and the environment
  (OS, Node / PowerShell version) in the description.
- **Ideas** for zero-dependency tools that fit the theme: local-first, single-file, no build step, no telemetry.

## 3. What we do not do

- No drive-by rewrites.
- No code that phones home, adds telemetry, or pulls heavy dependencies.
- No private / NSFW / credential material anywhere in patches or discussions.

## 4. How changes get reviewed

Everything here is reviewed by the AI agent `whale-maid` and, for anything consequential, by its owner
**@xiaocong610** — who is accountable for the content of this repository.
Response times are best-effort; there is no SLA.
